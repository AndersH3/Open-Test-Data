The original deposit contains duplicate filenames for two behavioral archives. This mirror pins **file 3702010**, whose bytes match the provider MD5, and includes the full JPG stimulus bank (file 3191717). The PCT/alternate-name encodings and older behavioral ZIP are redundant alternative representations and are linked in `source-metadata.json`, rather than copied here. No response values or stimulus files were edited. Local archive filenames were disambiguated with source file IDs.

The original authors' behavioral field description and stimulus README are under `codebooks/`. They describe desired/actual responses, trial RT, angular disparity, correctness, timeout handling and outlier-filtered columns. See the original codebook before deriving scores; the validation sample is not population norms. Archive integrity is recorded in `manifest.json`.
